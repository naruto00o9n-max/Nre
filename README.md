# مرسم المانهوا — نسخة أولية Android وiOS

تطبيق React Native / Expo ببناء أصلي، يستهدف تحرير الصفحات الطويلة دون تغيير أبعادها. هذه نسخة هندسية أولية؛ لم تُثبت بعد على جهاز حقيقي، وليست بديلًا مكتملًا لـ ibis Paint.

## التشغيل

```sh
npm install
npx expo prebuild --platform android
npx expo run:android
```

يتطلب Android SDK وJDK 21 ومحاكيًا أو هاتفًا. لا يعمل داخل Expo Go. يمكن إنشاء APK تجريبي عبر EAS (بعد ربط حسابك):

```sh
npx eas-cli build --platform android --profile preview
```

## المتاح

- استيراد PNG وJPEG وWebP إلى نسخة أصل محفوظة داخل التطبيق.
- عرض بالمقاطع، تكبير بإصبعين، تحريك بأداة التنقل.
- فرشاة لون وحجم بإحداثيات الصورة الأصلية.
- نص عربي متعدد الأسطر، خطوط النظام واستيراد TTF/OTF، وتغيير موضع النص بالنقر.
- كل نص أو ضربة فرشاة طبقة مستقلة: ترتيب، إخفاء، شفافية وحذف.
- تراجع وإعادة حتى 50 خطوة، وحفظ/فتح المشاريع داخل مساحة التطبيق.
- تصدير PNG واحد بالأبعاد الأصلية ومشاركته للحفظ.

## سلامة الصور الطويلة

`BitmapRegionDecoder` يفك المناطق المطلوبة؛ ذاكرة عرض المقاطع محدودة بـ24 مقطعًا، كل منها قرابة 512×512 بكسل بعد أخذ العينات. التصدير يعالج شرائح بارتفاع أقصى 256 صفًا، مستهدفًا نحو 8 MiB لكل bitmap، مع نسخة مؤقتة إضافية. `StreamingPng` يكتب صفوف RGBA بالتتابع عبر zlib؛ لا يُنشئ bitmap بحجم الصفحة كاملة ولا يستخدم لقطة الشاشة.

المعاينة منخفضة الدقة لا تُستخدم في التصدير. المصدر والعمليات مستقلان، والرسم والتصدير يستخدمان نفس Renderer. الحد التجريبي لعرض التصدير 32768 بكسل؛ ارتفاع الصورة يعتمد على decoder والملف والجهاز والوقت المتاح.

**لا نعد بتطابق شامل لكل صيغة ومدخل:** فك Android للصورة وتحويل الألوان وalpha premultiplication قد يغيّر بعض قيم الألوان، خصوصًا الشفافية الجزئية وملفات ICC. كاتب PNG يحفظ القيم التي يتلقاها دون فقد، لكن اختبار مسار الصورة الأصلي→Android→التصدير الكامل ما زال مطلوبًا. اتجاه EXIF وملفات الصور المتحركة/16-bit والألوان الواسعة غير مدعومة دعمًا موثّقًا. استخدم صور PNG/JPEG ثابتة باتجاه مخزّن صحيح وsRGB في هذه النسخة.

## الاختبارات

```sh
npm run check
npm test
java tests/CompileAndTest.java
npx expo export --platform android
```

اختبار Java يجمع **كاتب PNG نفسه المستخدم في المحرك**، ينتج صورة 257×50000، يفكها باستخدام ImageIO، ويقارن 12,850,000 بكسل RGBA. يتحقق أيضًا من رفض الملفات الناقصة. الاختبار بحد heap 128 MiB يشمل فك الصورة في الاختبار؛ المحرك لا يعتمد على ImageIO. اختبار ثانٍ ينتج صورة 2000×100000 (200 مليون بكسل) بحد heap 32 MiB، ثم يفحص كل البكسلات وCRC بتفكيك PNG تدريجي مستقل في Python.

## iPhone وIPA غير موقّعة

نجح [بناء iOS على GitHub Actions](https://github.com/naruto00o9n-max/Nre/actions/runs/37769992945) باستخدام macOS 26 وXcode 26.4.1. نزّل artifact باسم `manhwa-studio-unsigned-ipa`، ثم فك ضغطه ووقّع ملف IPA. يستهدف iOS 16.4 فأحدث، بمعمارية ARM64. انظر [تعليمات iOS والقيود](docs/ios-unsigned.md). الصور الطويلة جدًا على iOS تتطلب PNG حاليًا، وتحتاج مساحة ملف بكسلات على القرص. لم يُشغّل التطبيق على iPhone فعلي بعد.

## ما لم يكتمل

- ممحاة بكسلات، طبقات رسم مجمّعة، أقنعة، تحديد، قص، دمج طبقات، نسخ ولصق، ملتقط لون.
- سحب/تحجيم/تدوير النص مباشرة، استعادة قائمة الخطوط المستوردة بعد إعادة التشغيل (الخط المستخدم محفوظ داخل المشروع).
- استعادة تلقائية بعد إغلاق التطبيق، إدارة/حذف المشاريع، نقل المشروع خارج التطبيق مع أصله وخطوطه.
- تقدم التصدير وإلغاؤه، الاستكمال بالخلفية، تحقق ملفات المصدر، تسريع الرسم الكثيف.
- التحقق من الواجهة والإيماءات والذاكرة على أجهزة Android وiPhone؛ نجح تجميع Swift/Xcode.

حذف التطبيق يحذف المشاريع الداخلية. صدّر الصور المهمة إلى مكان خارجي.

انظر [البنية والاختبارات المطلوبة](docs/architecture.md).

## نسخة APK التجريبية

تم بناء APK مستقل لـ Android ARM64 (Android 7.0 فأحدث)، مع تضمين JavaScript؛ لا يحتاج إلى Metro أو Expo Go. موجود في ملفات التسليم باسم `manhwa-studio-android-arm64.apk`. نجح التحقق من التوقيع، لكن التشغيل الفعلي على جهاز لم يُختبر بعد.
