# Pro Image Editor — تجربة iPhone

تطبيق Flutter يستخدم الواجهات الرسمية Grounded وFrosted Glass وWhatsApp من [hm21/pro_image_editor](https://github.com/hm21/pro_image_editor)، عند commit `8305f0f1d734c96fc3bfe1411e8104ec628753f7`، إصدار 14.10.0.

تطبيق التجربة يوفر اختيار صورة من الصور أو الملفات، وصورة محلية للتجربة، ومعاينة الناتج وحفظه في الصور. واجهة التحرير وأدواتها هي أمثلة المشروع الأصلية. التعديلات عليها تقتصر على قبول ملفات محلية وإعداد التصدير PNG دون حد 2000 بكسل الافتراضي. هذا لا يزيل حدود Flutter/GPU للصور الهائلة، ولا يضمن تطابق الألوان أو دعم صفحات بطول 100000 بكسل.

افتح Actions ثم **Pro Image Editor unsigned IPA**. البناء يستهدف ARM64 وiOS 16.4 فأحدث، ويستخدم Flutter 3.47.x وXcode 26.4.1. تنزيل artifact باسم `pro-image-editor-unsigned-ipa` ثم فك ضغطه وتوقيع IPA بأداتك الخاصة. لا تتطلب عملية البناء شهادة Apple أو مفاتيح حساب.

المستودع يحفظ وصفة بناء قابلة للتكرار: يجلب Action المصدر الرسمي المثبت، وينشئ مشروع iOS بواسطة Flutter، ويطبق التعديلات الصغيرة من `scripts/prepare.py`. لا يستخدم محرّر React Native السابق.

المصدر الرسمي وأمثلة الواجهات يخضعان لترخيص BSD-3-Clause. تبقى إشعارات الحقوق والترخيص في المصدر المجلوب. توجد حزمة مصدر وملف dependencies lock ضمن artifact التشخيص للتوثيق.
