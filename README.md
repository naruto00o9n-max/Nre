# مرسم المانهوا — Frosted Glass

تطبيق Flutter مبني على **Pro Image Editor 14.10.0**، مع واجهته الزجاجية الأصلية وتعديلات مخصّصة لتحرير صور الفصول وتنظيمها. الفرع `pro-image-editor` هو تطبيق Flutter الحالي؛ الفرع `main` يحتوي النموذج القديم المختلف.

## ما يعمل في هذه النسخة

- بداية عربية ومعرض محلي: مجلد عمل ← مجلدات فصول ← مشاريع صور. المجلدات متداخلة، مع البحث وتغيير الاسم والنقل والمحذوفات القابلة للاستعادة واستيراد عدة صور.
- الأصل يُنسخ كما هو ولا يُستبدل عند الحفظ. المشروع يحفظ الطبقات مستقلّة، مع حفظ تلقائي ونسخة سابقة من الحالة ونسخة احتياطية من فهرس المعرض.
- محرّر زجاجي وخلفية داكنة، تحريك وتكبير بإصبعين، ملاءمة الصورة وملاءمة العرض. الحد الأعلى يستهدف نحو 12600% من دقة المصدر، وليس من حجم المعاينة.
- النقر على اللوحة يظهر «إضافة نص». خصائص النص: خطوط عربية مضمّنة، استيراد TTF/OTF، الحجم والمحاذاة واللون والخلفية والحدود والتباعد بين الحروف والأسطر وعرض المربع. النص يبقى قابلًا للتحرير، مع إطار ومقابض لا تتضخّم مع تكبير الصورة ومقبض لسحب عرض المربع.
- قائمة طبقات للترتيب والتحديد والإخفاء والقفل والشفافية والنسخ والحذف. طبقات نص ورسم وصور إضافية من الجهاز. الصورة الأصلية محفوظة مستقلة. هذه طبقات عناصر Pro Image Editor؛ ليست منظومة طبقات رسم نقطية وأقنعة ومزج بمستوى ibis Paint.
- أدوات الرسم والقص والتدوير والألوان والفلاتر والتمويه في المحرّر الأصلي. التراجع والإعادة أثناء الجلسة؛ المشروع يحفظ الحالة الحالية، وليس كامل سجل التراجع بعد إعادة فتحه.
- PNG للتصدير، مع الحفظ في الصور أو المشاركة / الحفظ في الملفات. حفظ المشروع لا يتطلب تصدير الصورة.

## الصور الطويلة: الحدود الفعلية

الهدف الذي حدّده المستخدم **800 × 15000**. لا نصغّر الصور لاستيرادها. حدّ النسخة الحالية: **15360 بكسل لكل ضلع، و24 مليون بكسل للصورة**؛ يُرفض تجاوز الحد بدل تقليل الجودة بصمت. يُرفض PNG ذو 16 بت بدل تحويله إلى 8 بت.

تصدير PNG المعدّل يرسم شرائط لا تتجاوز 2 MiB من RGBA ويضغطها في isolate كتيار zlib واحد، بدل سطح تصدير واحد بطول الصورة. بقي فك ترميز الصورة ومعاينتها في محرك Flutter الأصلي؛ **المعاينة ليست محرك صور مبلّطًا من القرص**، وبالتالي ما زالت الذاكرة وحدود GPU مهمة. لا توجد ضمانة لصور بطول غير محدود، أو لدقة 16 بت / HDR، أو للاحتفاظ بملفات ICC وEXIF في PNG الناتج. التصدير الحالي RGBA8. القص يغيّر الأبعاد عمدًا؛ التكبير والتحريك في مساحة العمل لا يغيّران أبعاد التصدير.

اختبارات على محرك Flutter تتحقق من جميع بكسلات صورة RGB8 اختبارية 800 × 15000 بعد التصدير من المحرّر: 12 مليون بكسل بلا اختلاف عند عدم تغيير المحتوى. وتتحقق من بقاء الأبعاد ومن اقتصار تغييرات النص والصورة الإضافية على منطقة محدودة ومن إعادة فتح الطبقات. هذه نتيجة للحالة الاختبارية، وليست إثباتًا لكل ملف أو لكل جهاز iPhone. يُضاف اختبار نفس التدفق على محاكي iOS إلى Actions؛ يجب مراجعة نتيجة التشغيل، ولا يُعتبر إنشاء IPA اختبارًا لجهاز حقيقي.

## البناء

Flutter 3.47.6 / Dart 3.13، iOS 16.4 فأحدث، Xcode 26.4.1. Android موجود في المشروع المتولّد ولم يُبنَ ضمن مهمة IPA الحالية.

```bash
git clone https://github.com/naruto00o9n-max/Nre.git --branch pro-image-editor
cd Nre
git clone https://github.com/hm21/pro_image_editor.git upstream
git -C upstream checkout 8305f0f1d734c96fc3bfe1411e8104ec628753f7
flutter config --no-enable-swift-package-manager
python3 scripts/prepare.py
flutter create --no-pub --platforms=ios,android --org com.manhwa --project-name proimageeditortrial app
python3 scripts/prepare.py
cd app
flutter pub get
flutter analyze
flutter test
flutter build ios --release --no-codesign
cd ..
bash scripts/package-ios.sh
```

Actions تُنشئ IPA غير موقّعة دون مفاتيح Apple، وتزيل التوقيعات من الملفات التنفيذية والإطارات، وتتحقق من ARM64 ومن بنية الأرشيف وSHA-256. يوقّعها المستخدم للتثبيت. ينتج البناء معرّف الحزمة `com.manhwa.proimageeditortrial`، واسم العرض «مرسم». التحليل والاختبارات تسبق إنتاج IPA.

المصدر مكرّر البناء عبر سكربت تجهيز واضح: `trial/studio_editor.dart` مشتق من المثال الزجاجي الرسمي، و`trial/studio` يحتوي المعرض والخصائص، و`patches/streaming_png.dart` وتعديلات `scripts/prepare.py` تحتوي تغييرات المحرك. خطوط Noto تُنزّل من commit ثابت وتُفحص SHA-256؛ رخص OFL محفوظة في `trial/fonts`. رخصة محرك Pro Image Editor هي BSD-3-Clause، المحفوظة في LICENSE.
